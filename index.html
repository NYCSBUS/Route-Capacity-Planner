Admin rules & assumptions used in the calculation

Changes apply immediately to the Outputs tab and are listed there under "rules in effect".

Vehicle → route substitution tick if a vehicle in the row may run a route of the column type

A vehicle always covers its own route type. Each type serves its own routes first; spare vehicles then cover other allowed route types.

Other rules

Off: only drivers limit staffing; attendants are ignored.

On: vehicles that cannot be parked are excluded from the fleet. Type C only at locations flagged "Type C allowed".

On: demand accumulates (recommended). Off: only routes starting that day are counted.

Fixed assumptions

  • Usable count = floor(count × (1 − spare %)). Spare factor is set by each owner on their tab.
  • Weeks start Monday. Pipeline entries are added at the start of the week entered; exits are an average per week, accumulated and rounded down.
  • "To close the gap" is grossed up for the spare factor so it reads as head-count / vehicles to add.
